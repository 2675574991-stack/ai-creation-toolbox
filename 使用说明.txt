AI 创作工具箱 开源版 v1.2
========================================

一个窗口，两个本地工具：

  ① 素材巢       AssetNest 项目素材资产管理
  ② 色卡生成器   图片主色 → 10 色卡

素材巢按「剧本 / 人物 / 场景 / 道具 / 音频 / 视频 / 成片」组织项目文件，
支持拖放导入/移动、缩略图与视频首帧、音频波形、提示词/生成参数读取、
评分标签备注、外部文件改动自动同步。

色卡生成器拖入 JPG / PNG / WebP 图片，提取 10 个主色，排成 1600px 宽的
黑底色卡，可选在色块下印一行风格提示词，保存为 PNG。


一、开源版不包含什么
----------------------------------------
H3 提示词医生、提示词框架工作台属于第三方内容，本仓库不分发它们的
代码和文案，因此开源版不包含这两个模块。请不要把原版完整包上传到
公开 Releases。


二、怎么运行
----------------------------------------
双击「AI创作工具箱.exe」即可。

运行环境
  · Windows 10 / 11（64 位）
  · Microsoft Edge WebView2 运行时（Win10/11 一般已自带）

注意
  exe 必须和同目录下的 3 个 dll、app.ico、web、vendor 文件夹放在
  一起，不要单独拷走。整个文件夹可整体复制到别的电脑。

首次启动会在 %LOCALAPPDATA%\AICreationBox-OSS 下建立数据目录。


三、快捷键
----------------------------------------
侧栏点击          切换工具
「自定义顺序」     用 ↑ ↓ 调整工具排列，保存后生效
拖拽侧栏工具      也可以直接拖拽排序
Ctrl + Enter      在色卡生成器中开始生成
F5                刷新当前界面
F12               开发者工具
Ctrl + 0          重置缩放

素材巢内保留原有快捷键：
空格 灯箱、Enter/F2/Del 打开/重命名/删除、1-5/F 评分收藏、
/ 聚焦搜索、方向键移动、Ctrl/Shift 点击多选。


四、文件保存
----------------------------------------
色卡图片等保存动作都会弹出 Windows 保存对话框。
素材巢的导出清单（CSV/JSON）走它自己的浏览器下载流程。


五、数据保存在哪
----------------------------------------
%LOCALAPPDATA%\AICreationBox-OSS
  · settings.ini       窗口位置、大小
  · WebView2\          界面缓存、localStorage
  · error.log          出错时生成

%LOCALAPPDATA%\AssetNest
  · assetnest.db       评分、标签、备注、最近项目
  · cache\             缩略图、视频封面、音频波形缓存


六、从源码构建
----------------------------------------
  1. 还原 WebView2 SDK：
     powershell -ExecutionPolicy Bypass -File scripts\fetch-webview2.ps1
  2. 构建素材巢（需要 Python 3.10+）：
     powershell -ExecutionPolicy Bypass -File scripts\build-assetnest.ps1
  3. 构建工具箱：
     powershell -ExecutionPolicy Bypass -File build.ps1 -SkipAssetNest

产物在 dist\AI创作工具箱。


七、说明
----------------------------------------
· 两个工具都在本机运行，不联网、不上传内容。
· 素材巢通过 127.0.0.1 上的随机端口提供本地界面，仅本机可访问；
  切换到素材巢时自动启动，关闭工具箱时自动结束。
· 色卡取色使用 median-cut 主色聚类，输出 1600px 宽 PNG。
